## Плавность и загрузка

Уже реализованы: задержка индикатора таблицы 180 мс, aria-busy, отмена устаревшего refresh через AbortController, сохранение существующих строк при ошибке обновления, reduced-motion стили. Это стоит сохранить.

Предлагаемая политика: первоначальная загрузка — каркас будущего экрана; обновление фильтров — существующие строки и компактный индикатор; сохранение формы — индикатор в кнопке с неизменной шириной; длительные операции — устойчивый блок прогресса в текущем окне. Не добавлять искусственную задержку показа готовых данных.

loading.php сейчас заменяет весь документ через document.write. Переход от центрального спиннера к полной панели визуально резко меняет композицию. При переработке первой загрузки сохранить геометрию будущих блоков и добавить понятное состояние долгого ожидания/ошибки.

Для микроанимаций ориентир: hover/focus 120–160 мс, dropdown/modal 160–220 мс. Это предлагаемые параметры, не результаты замера. Анимировать opacity/transform; не заставлять таблицу или кнопки подпрыгивать. Reduced motion должен действовать и в JS.

Кнопки форм: ориентир 40px высоты на desktop, область касания 44px на mobile. Иконки 16–18px с единым весом, стабильная ширина чисел и кнопок. Увеличивать приоритетные элементы и зоны нажатия, а не весь интерфейс.

## Границы проверки

Детектор Impeccable по templates вернул []; это не доказательство отсутствия UX-проблем и может быть ограничено поддержкой PHP. Overlay не внедрялся: браузер предоставляет только read-only evaluate. Новый сервер не запускался. Производственные данные не менялись. Временная мобильная ширина сброшена. Ошибка browser setChecked не доказывает дефект checkbox: выбор строки этим способом не удалось подтвердить.

Следующая проверка после исправлений: нижний/верхний per-page, фильтры без результатов, возврат из карточки, формы с ошибками, экспорт с собственным лимитом, медленная сеть, ширины 390/768/1440px, клавиатура, reduced motion. Измерять сдвиги и длительность взаимодействий до/после на одном наборе данных.
