# Завершение Dashboard — 9 сентября 2026

Продолжение согласованной работы `update-dashboard-performance-design`.

## Дополнения

- Карточки статусов показывают полный текст; исправлены скачки фильтров, переходы карточек, высота таблицы, прелоадер и состояния сохранения/восстановления (визуальная приёмка 8 сентября).
- Корзина и избранное обновляют серверную разметку списка без полной перезагрузки. Сохраняются фильтры, тема и позиция прокрутки; сервер корректирует номер страницы, счётчики и пустое состояние.
- После частичного сбоя массовой операции выполняется сверка с сервером. Ошибка самой сверки оставляет список видимым с кнопкой повторной загрузки; мутация автоматически не повторяется.
- На время мутации список блокируется от новых действий; старое предложение повторной загрузки убирается, чтобы не начать чтение посреди новой записи. Обработчики корзины переинициализируются без накопления; модальные окна переиспользуются.
- Фоновая сверка корзины не запускает автоочистку повторно.
- Методы логгера сохраняют контекст при передаче в обработчик ошибок. До исправления WebKit воспроизводил необработанное исключение `this._log` после отмены запроса при переходе между страницами.

## Проверки

- 25 Node-тестов плюс отдельный lazy-upload тест. Новые регрессии проверяют обновление списка, серверные счётчики/пагинацию, HTTP-ошибку, ответ страницы входа вместо списка и detached logger callbacks. До реализации новые тесты падали.
- 38 PHP unit-файлов прошли локально на PHP 7.3 и 8.2; синтаксис PHP проверен на 7.3. Три integration-теста прошли на MySQL 8 в отдельной `dashboard_test`.
- На локальных синтетических данных Chromium проверены повторное восстановление, повторное выделение после обновления, массовое восстановление до пустого состояния, выбор всех 30 записей через страницы, удаление из избранного до пустого состояния, одиночное и массовое окончательное удаление. Проверено сохранение JS-маркера документа: навигации после действий нет.
- Намеренный HTTP 503 при сверке после восстановления: блокировка снимается, повтор загружает актуальный список и не повторяет восстановление.
- Firefox и WebKit: главная, избранное и корзина, ширины 390 и 1440 px, обе темы; отсутствие горизонтального переполнения страницы, обрезания названий статусов и необработанных JS-ошибок; обновление списков. WebKit — дополнительная проверка движка, не проверка установленного Safari.
- Независимое ревью выявило гонку повторной загрузки с новой мутацией; исправлена до публикации.

## Ограничения измерений

Предыдущие замеры производительности приведены в `DASHBOARD_PERFORMANCE_2026-09-07.md`; они не заменяются результатами этой функциональной проверки. Полевые INP/FPS и скорость авторизованного дашборда на реальной пользовательской БД здесь не измерены. Проверка опубликованного сайта будет ограничена доступными без входа страницами и статическими ресурсами; реальные данные не изменяются для проверки.
