## Подтверждённые находки

1. **Повторное объявление внешнего шрифта.** `assets/css/core-base.css:8` содержит Google Fonts `@import` с семью весами; `templates/dashboard.php:46` подключает второй stylesheet с двумя весами. Это две разные CSS URL и внешняя цепочка обнаружения шрифта. Повторное скачивание одинаковых font-файлов не утверждается: оно зависит от браузерного кеша и ответов Google.
2. **Накопление обработчиков автообновления.** `assets/js/modules/auto-refresh.js` создаёт новый `visibilitychange` listener при каждом старте. Stop очищает интервал, но listener удаляется только на следующем событии видимости при выключенном режиме. VM-проверка с DOM/timer stubs: после 10 start/stop без смены видимости осталось 10 listeners. Если включить режим до смены видимости, старые listeners продолжают существовать. Нужен стабильный обработчик и явная очистка.
3. **Разные условия виртуализации.** `assets/js/table-module.js:161` и `:411` используют `perPage > 50`, `:435` — `perPage > 200`. Влияние зависит также от количества строк и threshold. Нужны общий предикат и проверки 25/50/100/200/500 строк, initial/AJAX и разных плотностей.
4. **Крупный синхронный пакет.** Манифест включает 26 скриптов в sync-бандл, в том числе модальные операции и экспорт. Скрипты находятся в конце body; это не равно блокировке всего head, но исполнение занимает главный поток. Порядок globals/TDZ уже становился причиной регрессий, поэтому механическая расстановка defer недопустима.
5. **Reduced motion непоследователен.** Базовый CSS снижает длительности, но делает исключение для бесконечного loader. `auto-refresh.js` задаёт JS scroll `behavior: 'smooth'` независимо от предпочтения пользователя. Требуется единая политика CSS и JS, включая поздние стили темы.
6. **Документация устарела.** README утверждает, что сборки нет; реально существуют `AssetBundles`, `tools/build_assets.php` и build-шаг деплоя. `openspec/project.md` говорит об отсутствии CI, хотя есть PHP 7.3/8.2 и MySQL-проверки. Старое предложение обещает ускорение статистики без актуальной базы замеров; переносить эти цифры в новый отчёт нельзя.

## Гипотезы, требующие стенда

- **Session lock:** auth запускает PHP-сессию; в `refresh.php` нет явного `session_write_close`. При файловом session handler долгие запросы одной сессии могут выстраиваться в очередь. Подтвердить handler, место всех session writes и параллельный trace, прежде чем менять код.
- **CSS-каскад:** восемь общих файлов, многочисленные mobile `!important`, поверх mobile загружается design layer и dark layer. Это риск конфликтов, но конкретные переполнения и проблемы контраста нужно воспроизвести в браузере.
- **Внешний noUiSlider:** dashboard загружает его с CDN. Проверить необходимость на первом экране и поведение при отсутствии сети; рассмотреть локальный vendor-файл и загрузку по потребности.
- **Широкая таблица и payload:** проверить число DOM-узлов и объём полей ответа на 25/100/500 строках. Не удалять поля, которые нужны копированию, редактированию и экспорту.
- **SQL:** исследовать медленные фильтры и глубокую пагинацию через EXPLAIN на тестовой копии. Наличие COUNT или OFFSET само по себе не доказывает проблему.
